# 自动化与运行适配记录

本项目没有预设“发现多少业务 Bug”的简历数字。标准账号购物流程的最终结果看 reports/results.xml。

保留的特殊账号（例如 locked_out_user、problem_user）是上游故意提供的练习场景，不能把这些演示行为包装为自己发现的线上缺陷。

工程适配：本地遥测适配器避免依赖外部错误上报；Chrome 使用独立可写临时配置和显式等待；Page Object 等待路由切换与字体就绪，减少打包版布局变化或异步渲染造成的自动化误判。失败截图与控制台信息可帮助区分页面问题和脚本问题。

检查点包括结算三项必填校验、中文输入、独立计算金额和完成后购物车状态。税率 8% 是示例业务规则，不是税务结论。
