# 修改前后与个人需求

基线：reports/baseline.xml，10 通过、5 失败。最终结果见 results.xml。

## BANK-REQ-01：本练习新增转账输入规则

先约定：金额必须大于 0；不能有超过两位的有效小数；不能向同一个账户转账；缺少金额返回 400。拒绝请求不应改变余额或产生流水。

修改前：0、-1、0.001 和同账户转账被允许；缺失金额请求返回 500。这 5 个输入在基线报告中失败。

实现：ParaBankServiceImpl.transfer 在调用事务管理器前检查 amount==null、signum、stripTrailingZeros().scale() 和账户 ID；不满足时抛出 BadRequestException，返回 400。

这里前三类约束是本次明确新增的练习需求，不把上游未实现自定义规则全部称为上游 Bug。保留原交易逻辑，不伪称设计了整套银行核心。

## BANK-CHECK-02：不存在目标账户时的事务回滚

给 2147483647 这个不存在的账户转 10，检查 HTTP 失败，原账户余额和流水数不变。基线已通过，改造后回归继续验证。回滚来自原系统事务机制；个人贡献是设计和实现外部验证用例，不是新增事务引擎。

该测试没有模拟真实资金、并发故障或支付清算。
