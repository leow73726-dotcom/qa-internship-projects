# 面向测试实习的三个个人实战项目

这是基于三个开源示例做的个人 QA 改造。原作者、源地址、固定提交和许可证均保留；新增内容是测试设计、自动化、明确的业务规则、缺陷修复、启动脚本和复现证据。

| 文件夹 | 它做什么 | 你练什么 |
| --- | --- | --- |
| swagcart-qa | 模拟购物网站 | Selenium 页面自动化、Page Object、结算校验 |
| clinicflow-qa | 宠物诊所后台接口 | Requests/Pytest、边界值、接口关联、缺陷复现 |
| bankflow-qa | 虚拟银行 | 金额守恒、流水核对、事务回滚、金融业务规则 |

先看 **新手开始.md**。双击 **开始使用.cmd** 可以选择应用和测试。三个项目共用根目录的 Python 环境和 tooling 工具，请保留整个文件夹。

推荐先学电商，再学诊所，最后学银行。不需要一天内全部看完。简历选你能自己操作、解释和修改的 1～2 个项目，搭配之前做过的 CaseBoard 即可。

本次代码与文档由 AI 协助完成。报告证明代码在本机实际执行过，不等于你已经理解全部实现。读懂并独立复现后，可据实写“基于开源项目开展测试与改造”；不应写成从零开发整个业务系统或公司实习经历。

`验证汇总.md` 记录实测结果；每个项目的 docs/ 有需求映射、缺陷记录和讲解；reports/ 保存 JUnit XML；`简历项目表述.md` 提供完成学习后的可用表述。
